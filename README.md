# Data Analysis and Visualisation in R 🚀

This is an introduction to the R programming language aimed at researchers with no programming experience. It is typically taught over the course of 2x 4 hour sessions.

The lesson starts by getting acquainted with the RStudio interface before covering some fundamentals of using R. It then moves to loading in data and exploring how to visualise it with `ggplot2`, a very popular plotting package. The next episode takes learners through an exploration of data frames, the objects R uses to store tabular data. Next are common data cleaning operations, before moving on to vectors and factors. The final episode introduces the flow of data analysis in R, and how to combine operations to subset and summarise data.

## Prerequisites

Learners need to follow the instructions on the lesson [website](https://tesaunders.github.io/r-intro/setup.html) to install R, RStudio, and some R packages, before attending. Two monitors are recommended to follow along with the instructor.
